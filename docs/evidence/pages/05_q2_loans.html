Q2. Personal-loan counts by age decade

No loan amount is present; this ranks counts only.

Code excerpt

groups=df.withColumn('age_decade',(F.floor(F.col('age')/10)*10).cast('int')).groupBy('age_decade')
groups=groups.agg(F.count('*').alias('clients'),F.sum((F.col('loan')=='yes').cast('int')).alias('loan_holders'))
groups=groups.withColumn('loan_pct',100*F.col('loan_holders')/F.col('clients')).orderBy(F.desc('loan_holders'),'age_decade')
groups.show(5)
